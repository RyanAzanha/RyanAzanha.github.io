Perfil

IAM e segurança ofensiva olham para o mesmo alvo. Boa parte dos ataques reais passa por identidade: credenciais expostas, privilégios em excesso, contas esquecidas e RBAC mal desenhado. Como analista de IAM, sei como esses acessos são concedidos e administrados no dia a dia. Como pentester, estudo como eles são explorados. Uma frente melhora a outra.

Laboratórios práticos

Oito laboratórios do curso Introdução ao Hacking e Pentest 3.0 (Solyd), cada um focado em uma classe de vulnerabilidade. Resumo das habilidades demonstradas — sem soluções nem flags.

Linux / Enumeração

Fundamentos de Linux

Orientação em um sistema sem interface: listagem, arquivos ocultos por convenção, permissões e reconhecimento de conteúdo codificado versus cifrado.

Content Discovery

Descoberta de conteúdo web

Levantamento de superfície: mapeamento de recursos e diretórios do servidor que não são referenciados por nenhum link da página inicial.

Recon → Foothold

Do scan ao acesso

Enumeração de serviços de um host legado fora de inventário, identificação do que cada serviço entrega e obtenção de acesso inicial como usuário do servidor web.

SQL Injection

Extração de banco de dados

Teste black-box de um e-commerce com consultas ao banco mal construídas, levando à extração de dados via injeção de SQL.

XSS / Sessão

Roubo de sessão

Mural público sem sanitização de entrada: exploração de Cross-Site Scripting para alcançar uma área administrativa protegida apenas por cookie.

Path Traversal

Leitura de arquivos do servidor

Parâmetro que aceita nome de arquivo sem validação: travessia de diretório para ler conteúdo fora da pasta pretendida.

Rede interna

Pivô para a rede interna

A partir de um servidor com saída para a internet, alcance de um painel de operações em rede sem rota externa — que não deveria ser acessível.

Broken Access / IDOR

Controle de acesso na API

Teste autenticado de uma API: a interface só mostra ações sobre o que é do usuário, mas o back-end não valida a autorização da mesma forma.
